# Telegram-бот с ИИ

Это мой первый проект на Python — писал его практически с нуля, параллельно осваивая сам язык. Начиналось как простой FAQ-бот, отвечающий по ключевым словам, а закончилось полноценным ботом с интеграцией языковой модели, который может вести осмысленный диалог, а не просто искать совпадения в словаре.

## Что умеет



- Отвечает на частые вопросы по заранее заданным темам (хранятся в отдельном JSON-файле, легко редактировать без изменения кода)
- На всё остальное — отвечает через LLM (Groq API), то есть может поддержать более живой разговор
- Есть команды и inline-кнопки для навигации
- Запоминает последнее сообщение пользователя в рамках сессии
- Умеет вежливо реагировать, если прислали не текст (голосовое, стикер и т.п.), а не просто молчать

## На чём написан

Python, библиотека `python-telegram-bot`, интеграция с LLM через OpenAI-совместимый API (Groq). Токены и ключи вынесены в переменные окружения — в коде их нет.

## Как это работает "под капотом"

Бот развёрнут на Railway и работает круглосуточно, без необходимости держать компьютер включённым. Код лежит в этом репозитории, оттуда же и деплоится — типичный рабочий процесс через Git.

## Почему я это делал

Я новичок в программировании и заходил в это без опыта — было интересно посмотреть, насколько быстро реально дойти от "не знаю Python вообще" до работающего продукта в облаке. Оказалось, быстрее, чем я думал, если делать на реальной задаче, а не проходить курс за курсом.
